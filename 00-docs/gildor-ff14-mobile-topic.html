Game: Final Fantasy XIV Mobile (official site)
UE4 version: 4.25
AES key: in the same place as usual (link)

Use specific build from this topic with game specific override. Most materials for skeletal meshes are not applied properly, because the game is using custom methods for it.

With specific build you can open packages directly, but if you want to extract some assets, which are not supported by umodel, you can use respective quickbms script from specific scripts bundle, available in topic with keys. For more info read sticked topic and this post.

Update: For latest game versions you need to extract packages with the script mentioned above anyway, and then open extracted assets in specific build.
