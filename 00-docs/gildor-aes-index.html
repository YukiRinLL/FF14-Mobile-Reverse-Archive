Where to find AES keys for Fortnite:

Keys for latest version are available here. Up-to-date archive with keys for previous versions is available here.

The collection of older Fortnite AES keys can now be found on this link (Updated 01/02/2022).


Where to find AES keys for other UE4/5 games (including mobile games):

You can find big collection of AES keys, which is being constantly updated, in this topic at rin forums, along with specific quickbms scripts required for some games. You need to be registered there to see attachments with tools and scripts.

In addition, that topic contains other useful information and tools, such as:
1) AES Finder (for PC games) and AES Finder mobile (for mobile games). With the help of those programs you can find keys by yourself, if the game is not protected. Please read readme files, included with both programs, to avoid possible issues.
2) Information about how to bypass simple game protections, so you could use finders on them.
3) Information about all PUBG games, because there are a lot of misunderstandings about them.  
4) Instruction about how to extract paks from PS4 games.
5) Specific UE bms scripts for quickbms. Some UE games has custom pak format, unsupported by umodel, so you should unpack them first with corresponding script and then open resulted assets in umodel.

You can also request AES keys in that topic, but please read the first post there before doing so (especially exceptions list). If you have any related questions, please go and ask them in that topic. This post is just for reference.  
Note that first one or two posts on rin forums will be pre-moderated, so they will not appear instantly. Please be patient and thanks for your understanding.
